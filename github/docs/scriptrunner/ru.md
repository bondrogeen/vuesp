# ScriptRunner — синтаксис и руководство пользователя

Версия: 1.3.0  
Обновлено: 2026-08-28

## Введение

ScriptRunner — это интерпретатор скриптов для ESP8266/ESP32 с кооперативной многозадачностью. Скрипты позволяют управлять портами, переменными, событиями и внешними функциями.

## Основные правила

### Разделитель команд

Все команды разделяются точкой с запятой `;`.

    $u0=0;while:$u0<10;log($u0);$u0=$u0+1;wait(1s);end;

### Пробелы

Пробелы допустимы внутри выражений (в правой части присваивания, в аргументах функций, в тернарном операторе). Они игнорируются парсером.

**Где можно ставить пробелы:**

- Вокруг операторов: `$u0 = 10 + 5`
- В тернарном операторе: `$u0 > 5 ? 100 : 0`
- В параметрах функций: `log('Hello', $u0)`

**Где нельзя ставить пробелы:**

- Между командами (команды разделяются только `;`).
- Внутри ключевых слов: `if:`, `while:`, `on(`, `end`, `else`.
- В суффиксах времени: `100ms`, `1s` — без пробела.

**Рекомендация:** для краткости и надёжности лучше не использовать пробелы в скриптах.

### Строки

Только одинарные кавычки `'`.

    $s0='Hello World';
    log('Temperature:',$temp);
    on('btn');

### Комментарии

Комментарии не поддерживаются.

## Переменные

| Тип                      | Синтаксис | Пример        |
| ------------------------ | --------- | ------------- |
| Целое беззнаковое        | `$uN`     | `$u0=255`     |
| Целое знаковое           | `$iN`     | `$i0=-10`     |
| Число с плавающей точкой | `$fN`     | `$f0=3.14`    |
| Строка                   | `$sN`     | `$s0='Hello'` |
| Массив                   | `$aN`     | `$a0={1,2,3}` |
| Порт (пин)               | `$pN`     | `$p14=255`    |

`N` — номер переменной от 0 до 9.

## Задержки (wait)

    wait(10ms);   // 10 миллисекунд
    wait(100ms);  // 100 миллисекунд
    wait(500ms);  // 500 миллисекунд
    wait(1s);     // 1 секунда
    wait(5s);     // 5 секунд
    wait(1m);     // 1 минута
    wait(5m);     // 5 минут
    wait(1h);     // 1 час
    wait(1);      // 1 секунда (совместимость)

**Важно:**

- Минимальная реальная задержка ~10 мс
- Только целые числа
- Без пробелов между числом и суффиксом

## Работа с портами

### Запись значения

    $p2=255;      // Включить (ШИМ)
    $p14=128;     // Половина яркости (ШИМ)
    $p0=0;        // Выключить

### Плавное изменение (Fade)

    fade(14,255,2000);  // Плавно до 255 за 2 секунды
    fade(13,0,1000);    // Плавно до 0 за 1 секунду

Формат: `fade(gpio, value, time)`

- `gpio` — номер пина
- `value` — конечное значение (0–255)
- `time` — длительность в миллисекундах

### Чтение значения

    $u0=$p0;      // Прочитать пин 0 в переменную
    log('Pin0:',$p0);

### Ограничения

- INPUT порты (кнопки): только чтение, генерируют события
- OUTPUT порты (светодиоды): чтение и запись

## События

### Формат событий для кнопок

События генерируются автоматически при изменении состояния INPUT портов:

- `btn` — любое изменение
- `btn_c` — нажатие
- `btn_l` — удержание 1–2 секунды
- `btn_r` — удержание > 2 секунд (повторение каждые 100 мс)

### Обработчик события

    on('btn');
      $p2=255;
      wait(200ms);
      $p2=0;
    end;

## Управляющие конструкции

### While цикл

    $u0=0;
    while:$u0<10;
      log($u0);
      $u0=$u0+1;
      wait(1s);
    end;

### If / Else

    $u0=5;
    if:$u0>10;
      log('Greater');
    else;
      log('Less or equal');
    end;

### Сложные условия

    if:$u0>=0&&$u0<=10;
      log('In range');
    end;

    if:$u0==10||$u0==20;
      log('Ten or twenty');
    end;

## Логирование (log)

    log('Hello');
    log('Count:',$u0);
    log('Pin0=',$p0,'Pin1=',$p1);
    log($u0,$u1,$u2);
    log('Temp:',$temp,'Hum:',$hum);

**Особенности:**

- Поддерживает несколько параметров через запятую
- Автоматически добавляет пробел между параметрами
- Строки только в одинарных кавычках

## Выражения и операторы

В скриптах доступны полноценные выражения с операторами, скобками и тернарным условным оператором.

### Арифметические операторы

    $u0=10+5;
    $u1=10-3;
    $u2=10*3;
    $u3=10/3;
    $u4=10%3;    // остаток

### Битовые операторы

    $u4=10&3;     // AND
    $u5=10|3;     // OR
    $u6=10^3;     // XOR
    $u7=10<<2;    // Сдвиг влево
    $u8=10>>1;    // Сдвиг вправо

### Операторы сравнения

Доступны в выражениях (не только в `if`/`while`):

    $u0=5>3?1:0;          // 1
    $u1=10==10?100:0;     // 100
    $u2=$u0!=0?$u0:0;     // 1
    $u3=(2+3)*4>10?1:0;   // 1

Полный список: `==`, `!=`, `<`, `>`, `<=`, `>=`

### Тернарный оператор (`? :`)

Условный оператор, позволяющий выбирать значение в зависимости от условия.  
Работает **только в выражениях** (в правой части присваивания, в аргументах функций, в `log`).  
**Не работает** в условиях `if` и `while`.

**Синтаксис:**

    условие ? значение_если_истина : значение_если_ложь

**Примеры:**

    $u0=10>5?100:0;            // $u0=100
    $u1=$u0>50?$u0*2:$u0/2;
    $s0=$u0==0?'zero':'non-zero';
    $p14=$u0>100?255:0;
    $f0=3.14;
    $f1=$f0>3.0?6.28:1.57;

    // Вложенность со скобками (поддерживается)
    $u0=5;
    $u1=$u0>0?($u0<10?1:2):0;   // $u1=1

    // Группировка сложных выражений
    $u2=(($u0+$u1)*2)>10?100:0;

**Круглые скобки** `( )` поддерживаются для явного задания порядка вычислений.

### Унарное отрицание `!`

Логическое НЕ. Применяется к числу, переменной, строке или массиву. Результат — целое число `1` (истина) или `0` (ложь).

**Примеры:**

    $u0=0;
    $u1=!$u0;          // $u1=1
    $s0='';
    $u2=!$s0;          // $u2=1 (пустая строка → ложь → инверсия)
    $u3=!5;            // 5 → истина → инверсия → 0
    $u4=!$u0?100:55;   // $u4=100

**Приоритет операторов (слева направо):**

1. Унарные: `-`, `~`, `!`
2. Арифметические: `*`, `/`, `%`, `+`, `-`
3. Битовые: `&`, `^`, `|`
4. Сдвиги: `<<`, `>>`
5. Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
6. Тернарный: `? :`

**Важно:** приоритет вычисляется строго слева направо. Для изменения порядка используйте скобки.

## Работа с массивами

    // Инициализация
    $a0={1,2,3,4,5};

    // Длина массива
    $u0=len($a0);

    // Чтение элемента
    $u1=get($a0,0);

    // Запись элемента
    set($a0,2,10);

    // Заполнение
    $u0=0;
    while:$u0<5;
      set($a0,$u0,$u0*10);
      $u0=$u0+1;
    end;

## Работа со строками

    // Конкатенация
    $s0='Hello ';
    $s1='World';
    $s2=$s0+$s1;

    // Длина строки
    $u0=len($s0);

    // Код первого символа
    $u1=ord($s0);    // 'H' -> 72

    // Символ по коду
    $s3=chr(65);     // 65 -> 'A'

## Внешние функции и переменные

    $temp=udp(2);
    $hum=fade(2,255,1000);

    log('Temp:',$temp);
    if:$temp>30;
      log('Too hot!');
    end;

## Примеры скриптов

### Мигание светодиодом

    $p2=255;wait(500ms);$p2=0;wait(500ms);

### Счётчик

    $u0=0;while:$u0<10;log('Count:',$u0);$u0=$u0+1;wait(1s);end;log('Done!');

### Плавное зажигание

    $u0=0;
    while:$u0<5;
      fade(14,255,1000);
      wait(1s);
      fade(14,0,1000);
      wait(1s);
      $u0=$u0+1;
    end;

### Кнопка управляет светодиодом

    $state=0;
    on('btn_c');
      if:$state==0;
        $state=1;
        $p2=255;
        log('ON');
      else;
        $state=0;
        $p2=0;
        log('OFF');
      end;
    end;

## Ограничения

- Максимальная длина скрипта: 256 символов
- Максимум скриптов одновременно: 15
- Минимальная задержка: ~10 мс
- Нет пробелов вне выражений (внутри выражений пробелы допустимы)
- Только одинарные кавычки `'`
- Нет дробных чисел в `wait()`
- Нет комментариев
