# ScriptRunner — синтаксис и руководство пользователя

@meta:version=1.0.0
@meta:last_update=2024-01-15
@meta:lang=ru

## Введение

ScriptRunner — это интерпретатор скриптов для ESP8266/ESP32 с кооперативной многозадачностью. Скрипты позволяют управлять портами, переменными, событиями и внешними функциями.

---

## Основные правила

### Разделитель команд
Все команды разделяются точкой с запятой `;`

@code
$v0=0;while:$v0<10;log($v0);$v0=$v0+1;wait(1s);end;
@end

### Пробелы
**Запрещены** вне строковых литералов.

Правильно:
@code
$v0=10;if:$v0>5;log('Greater');end;
@end

Неправильно:
@code
$v0 = 10; if : $v0 > 5; log('Greater'); end;
@end

### Строки
Только **одинарные кавычки** `'`

@code
$s0='Hello World';
log('Temperature:',$temp);
on('btn_13_1');
@end

### Комментарии
Комментарии **не поддерживаются**.

## Переменные

@table
| Тип | Синтаксис | Пример |
|-----|-----------|--------|
| Целое беззнаковое | $vN | $v0=255 |
| Целое знаковое | $iN | $i0=-10 |
| Число с плавающей точкой | $fN | $f0=3.14 |
| Строка | $sN | $s0='Hello' |
| Массив | $aN | $a0={1,2,3} |
| Порт (пин) | $pN | $p14=255 |
@end

@note: N — номер переменной от 0 до 9

## Задержки (wait)

@code
wait(10ms);   // 10 миллисекунд
wait(100ms);  // 100 миллисекунд
wait(500ms);  // 500 миллисекунд
wait(1s);     // 1 секунда
wait(5s);     // 5 секунд
wait(1m);     // 1 минута
wait(5m);     // 5 минут
wait(1h);     // 1 час
wait(1);      // 1 секунда (совместимость)
@end

@warning
- Минимальная реальная задержка ~10ms
- Только целые числа
- Без пробелов между числом и суффиксом
@end

## Работа с портами

### Запись значения
@code
$p2=255;      // Включить
$p14=128;     // Половина яркости
$p0=0;        // Выключить
@end

### Плавное изменение (Fade)
@code
$p14=255/20;  // Плавно до 255 за 2 секунды
$p14=0/10;    // Плавно до 0 за 1 секунду
@end

**Формат:** $pN=значение/десятые_секунды
- десятые_секунды — количество шагов по 100ms
- 10 = 1 секунда, 20 = 2 секунды

### Чтение значения
@code
$v0=$p0;      // Прочитать пин 0 в переменную
log('Pin0:',$p0);
@end

### Ограничения
- INPUT порты (кнопки): только чтение, генерируют события
- OUTPUT порты (светодиоды): чтение и запись

## События

### Формат событий для кнопок

События генерируются автоматически при изменении состояния INPUT портов:

@code
btn_<gpio>          // Любое изменение на порту
btn_<gpio>_<value>  // Конкретное значение (0 или 1)
@end

### Обработчик события
@code
on('btn_13_1');
$p2=255;
wait(200ms);
$p2=0;
end;
@end

### Генерация события
@code
emit('my_event');
@end

### Примеры событий для кнопок

@table
| Событие | Описание |
|---------|----------|
| btn_13 | Любое изменение на пине 13 |
| btn_13_1 | Пин 13 стал 1 (нажатие) |
| btn_13_0 | Пин 13 стал 0 (отпускание) |
| btn_2 | Любое изменение на пине 2 |
| btn_2_1 | Пин 2 стал 1 (нажатие) |
| btn_2_0 | Пин 2 стал 0 (отпускание) |
@end

## Управляющие конструкции

### While цикл
@code
$v0=0;
while:$v0<10;
log($v0);
$v0=$v0+1;
wait(1s);
end;
@end

### If/Else
@code
$v0=5;
if:$v0>10;
log('Greater');
else;
log('Less or equal');
end;
@end

### Сложные условия
@code
if:$v0>=0&&$v0<=10;
log('In range');
end;

if:$v0==10||$v0==20;
log('Ten or twenty');
end;
@end

### Вложенные конструкции
@code
$temp=read_temp();
if:$temp>30;
log('Hot!');
if:$temp>40;
log('CRITICAL!');
emit('overheat');
end;
else;
log('Normal');
end;
@end

## Логирование (log)

@code
log('Hello');
log('Count:',$v0);
log('Pin0=',$p0,'Pin1=',$p1);
log($v0,$v1,$v2);
log('Temp:',$temp,'Hum:',$hum);
@end

**Особенности:**
- Поддерживает несколько параметров через запятую
- Автоматически добавляет пробел между параметрами
- Строки только в одинарных кавычках

## Математические операции

@code
$v0=10+5;
$v1=10-3;
$v2=10*3;
$v3=10/3;

$v4=10&3;     // AND
$v5=10|3;     // OR
$v6=10^3;     // XOR
$v7=10<<2;    // Сдвиг влево
$v8=10>>1;    // Сдвиг вправо
$v9=10%3;     // Остаток от деления
@end

## Работа с массивами

@code
// Инициализация
$a0={1,2,3,4,5};

// Длина массива
$v0=len($a0);

// Чтение элемента
$v1=get($a0,0);

// Запись элемента
set($a0,2,10);

// Заполнение
$v0=0;
while:$v0<5;
set($a0,$v0,$v0*10);
$v0=$v0+1;
end;
@end

## Работа со строками

@code
// Конкатенация
$s0='Hello';
$s1='World';
$s2=$s0+' '+$s1;

// Длина строки
$v0=len($s0);

// Код первого символа
$v1=ord($s0);    // 'H' -> 72

// Символ по коду
$s3=chr(65);     // 65 -> 'A'

// Доступ к символу
$v2=get($s0,0);  // Первый символ
set($s0,0,72);   // Меняем первый символ
@end

if:$temp>30;

## Примеры скриптов

### Мигание светодиодом
@code
$p2=255;wait(500ms);$p2=0;wait(500ms);
@end

### Счетчик
@code
$v0=0;while:$v0<10;log('Count:',$v0);$v0=$v0+1;wait(1s);end;log('Done!');
@end

### Плавное зажигание
@code
$p14=255/20;wait(2s);$p14=0/20;
@end

### Кнопка управляет светодиодом
@code
$state=0;
on('btn_13_1');
if:$state==0;
$state=1;
$p2=255;
log('ON');
else;
$state=0;
$p2=0;
log('OFF');
end;
end;
@end

### Умный свет с двумя кнопками
@code
$brightness=128;
$state=0;

on('btn_13_1');
if:$state==0;
$state=1;
$p14=$brightness/10;
log('ON');
else;
$state=0;
$p14=0/20;
log('OFF');
end;
end;

on('btn_2_1');
if:$state==1;
$brightness=$brightness+32;
if:$brightness>255;$brightness=255;end;
$p14=$brightness/10;
log('Brightness:',$brightness);
end;
end;
@end

### Свет с датчиком движения
@code
$state=0;

on('motion');
$state=1;
$p14=255/10;
log('Motion detected!');
end;

on('idle');
$state=0;
$p14=0/20;
log('No motion');
end;

while:$v0==1;
$motion=read_motion();
if:$motion==1&&$state==0;emit('motion');end;
if:$motion==0&&$state==1;emit('idle');end;
wait(100ms);
end;
@end

## Ограничения

- Максимальная длина скрипта: 256 символов
- Максимум скриптов: 15
- Минимальная задержка: ~10ms
- Нет пробелов вне строк
- Только одинарные кавычки '
- Нет дробных чисел в wait()
- Нет комментариев

## Краткая шпаргалка

@table
| Что | Как |
|-----|-----|
| Разделитель | ; |
| Строки | 'текст' |
| Пробелы | только внутри строк |
| Переменные | $v0, $i0, $f0, $s0, $a0, $p0 |
| Задержка | wait(100ms), wait(1s), wait(1m), wait(1h) |

| Условие | if:условие; ... else; ... end; |
| Событие | on('имя'); ... end; |
| Генерация события | emit('имя'); |
| Лог | log(параметр1,параметр2,...); |
| Плавное изменение | $p14=255/20; |
@end
