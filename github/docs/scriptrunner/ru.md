# ScriptRunner — байткод-скрипты

Версия: 2.0.0
Обновлено: 2026-11-27

> Единственный движок: исходник компилируется в браузере в контейнер VBC1,
> прошивка проверяет его и исполняет. Текстовый раннер и `scripts.txt` удалены.
> Подробности формата — [bytecode-v1.md](./bytecode-v1.md).

## Введение

ScriptRunner позволяет управлять портами, переменными, событиями и внешними
функциями устройства. Скрипты создаются в студии `/script/`, компилируются в
браузере и сохраняются на устройстве единым пакетом `/www/scripts.bc`.

Особенности:

- компиляция и диагностика — в вебе, на МК исполняется проверенный байткод;
- до 15 скриптов, автозапуск — скрипт с именем `boot`;
- `wait()` не блокирует `loop()`;
- ошибка останавливает только свой скрипт и видна в `KEY_SCRIPTSTATUS` (WebSocket).

## Основные правила

- Синтаксис похож на JavaScript, но переменные — фиксированные слоты.
- Команды разделяются `;`, допустимы переносы строк.
- Комментарии: `//` и `/* */`.
- Строки — в одинарных или двойных кавычках, с экранированием.
- Скрипт без `on(...)` выполняется сверху вниз; обработчики запускаются событиями.

## Переменные

| Слот | Назначение | Доступно |
|---|---|---|
| `$uN` | беззнаковое целое | 0–9 |
| `$iN` | целое со знаком | 0–9 |
| `$fN` | float | 0–4 |
| `$sN` | строка (до 31 символа) | 0–1 |
| `$aN` | массив (до 64 байт) | 0–4 |
| `$pN` | GPIO | 0–15 |
| `$eN` | параметры события | 0–3, только чтение |
| `$cN` | параметры `call()` | 0–3, только чтение |

`$name` (например, `$display`) — переменная данных устройства. Доступные имена
и их типы приходят из `/vm/capabilities` и подсказок устройства.

## Работа с портами

```js
$p13 = 255;      // записать значение (0–255 для PWM)
$u0 = $p13;      // прочитать
```

Номер — GPIO. Для входов и выходов используется текущий режим порта из настроек
устройства; запись в вход не меняет режим.

## События

```js
on('btn_c') {
  log('gpio', $e0, 'value', $e1, 'count', $e2);
}
```

События: `btn`, `btn_c`, `btn_l`, `btn_r`. Доступны `$e0…$e3` — параметры
события; записывать в них нельзя.

## Управляющие конструкции

```js
if ($u0 > 10) {
  $p13 = 255;
} else {
  $p13 = 0;
}

while ($u0 < 5) {
  $u0 = $u0 + 1;
  if ($u0 == 3) { continue; }
  if ($u0 == 5) { break; }
  wait(100ms);
}
```

`wait(10ms | 1s)` приостанавливает только текущий скрипт. `return` завершает
обработчик события.

## Логирование (log)

```js
log('text', $u0, $s0);
```

До 8 аргументов. Сообщения появляются в панели логов студии и в WebSocket
сообщении `KEY.MESSAGE`.

## Выражения и операторы

- арифметика: `+ - * / %`, отрицание `-`;
- битовые: `& | ^ ~ << >>`;
- сравнения: `== != < <= > >=`;
- логические: `&& || !`;
- тернарный оператор: `$u0 > 5 ? 100 : 0`;
- скобки и стандартный приоритет.

> `&&`/`||` вычисляются без короткого замыкания — обе части всегда выполняются.

## Работа с массивами

```js
$a0 = [1, 2, 3];
$u0 = get($a0, 1);
set($a0, 1, 9);
$u1 = len($a0);
```

Массив хранит байты 0–255, до 64 элементов. Доступ по `$a0[1]`.

## Работа со строками

```js
$s0 = 'hello';
$u0 = len($s0);
$u1 = ord($s0);
$s1 = chr(65);
```

Строки конкатенируются через `+`. В переменную `$sN` помещается до 31 символа.

## Внешние функции и переменные

- `fade(gpio, value, time)` — плавно изменить PWM/DAC;
- `udp(id, text)` — отправить текст устройству в Vuesp Discovery;
- `http(method, url, ...)` — HTTP-запрос;
- `var(id [, value])` — переменная Modbus-профиля (если Modbus включён);
- `modbus(device, point [, value])` — точка Modbus-профиля (если Modbus включён).

Список функций и их аргументов всегда доступен в `/vm/capabilities`;
описания для подсказок — в `vue/json/suggestions.json` проекта устройства.

## Примеры скриптов

```js
// boot
log('boot');
$p13 = 128;
wait(500ms);
$p13 = 0;
```

```js
// button
on('btn_c') {
  log('click', $e0, $e1, $e2);
  $p13 = $e1 ? 255 : 0;
}
```

```js
// chain
call('display');
```

`call('name', ...)` запускает другой сохранённый скрипт; аргументы доступны через
`$c0…$c3`. Возврата значения нет, рекурсия запрещена.

## Ограничения

- до 15 сохранённых скриптов, 3 в RAM-кэше (`VBC_CACHE_SLOTS`);
- до 1024 байт кода на скрипт;
- стек до 64 значений;
- до 4 аргументов у `call()`, глубина вызовов — 4;
- 32 инструкции или 300 µs на скрипт за проход, 3 ms общий бюджет;
- имена скриптов: lowercase, 1–16 символов.

## Краткая шпаргалка

```js
$u0 = 0;                    // переменная
$p13 = 255;                 // GPIO
$s0 = 'ok';
log($s0, $u0);
if ($u0 > 0) { ... } else { ... }
while ($u0 < 5) { $u0 = $u0 + 1; wait(100ms); }
on('btn_c') { log($e0, $e1, $e2); }
call('other');
```
