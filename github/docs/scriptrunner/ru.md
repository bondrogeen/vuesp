# ScriptRunner — синтаксис и руководство пользователя

Версия: 1.2.0
Обновлено: 2026-08-15


## Введение

ScriptRunner — это интерпретатор скриптов для ESP8266/ESP32 с кооперативной многозадачностью. Скрипты позволяют управлять портами, переменными, событиями и внешними функциями.


## Основные правила

### Разделитель команд

Все команды разделяются точкой с запятой ;

```scriptrunner
$v0=0;while:$v0<10;log($v0);$v0=$v0+1;wait(1s);end;
```

### Пробелы

Запрещены вне строковых литералов.

Правильно:
$v0=10;if:$v0>5;log('Greater');end;

Неправильно:
$v0 = 10; if : $v0 > 5; log('Greater'); end;

### Строки

Только одинарные кавычки '

```scriptrunner
$s0='Hello World';
log('Temperature:',$temp);
on('btn');
```

### Комментарии

Комментарии не поддерживаются.


## Переменные

Тип          Синтаксис    Пример
Целое беззнаковое  $vN    $v0=255
Целое знаковое     $iN    $i0=-10
Число с плавающей точкой  $fN  $f0=3.14
Строка             $sN    $s0='Hello'
Массив             $aN    $a0={1,2,3}
Порт (пин)         $pN    $p14=255

N — номер переменной от 0 до 9.


## Задержки (wait)

wait(10ms);   // 10 миллисекунд
wait(100ms);  // 100 миллисекунд
wait(500ms);  // 500 миллисекунд
wait(1s);     // 1 секунда
wait(5s);     // 5 секунд
wait(1m);     // 1 минута
wait(5m);     // 5 минут
wait(1h);     // 1 час
wait(1);      // 1 секунда (совместимость)

Важно:
- Минимальная реальная задержка ~10ms
- Только целые числа
- Без пробелов между числом и суффиксом


## Работа с портами

### Запись значения

```scriptrunner
$p2=255;      // Включить (ШИМ)
$p14=128;     // Половина яркости (ШИМ)
$p0=0;        // Выключить
```

### Плавное изменение (Fade)

```scriptrunner
fade(14,255,2000);  // Плавно до 255 за 2 секунды (ШИМ)
fade(13,0,1000);    // Плавно до 0 за 1 секунду (ШИМ)
```

Формат: fade(gpio:number,value:number,time:number)


### Чтение значения

```scriptrunner
$v0=$p0;      // Прочитать пин 0 в переменную
log('Pin0:',$p0);
```

### Ограничения

- INPUT порты (кнопки): только чтение, генерируют события
- OUTPUT порты (светодиоды): чтение и запись


## События

### Формат событий для кнопок

События генерируются автоматически при изменении состояния INPUT портов:

btn          // Любое изменение на порту
btn_click  // количество нажатий
btn_long // Удержание 1-2сек
btn_repeat  // Удержание > 2сек (повторение каждые 100мсек)

### Обработчик события

```scriptrunner
on('btn');
$p2=255;
wait(200ms);
$p2=0;
end;
```

## Управляющие конструкции

### While цикл

```scriptrunner
$v0=0;
 while:$v0<10;
 log($v0);
 $v0=$v0+1;
 wait(1s);
end;
```

### If/Else

```scriptrunner
$v0=5;
if:$v0>10;
 log('Greater');
else;
 log('Less or equal');
end;
```
### Сложные условия

```scriptrunner
if:$v0>=0&&$v0<=10;
 log('In range');
end;

if:$v0==10||$v0==20;
 log('Ten or twenty');
end;
```

## Логирование (log)

```scriptrunner
log('Hello');
log('Count:',$v0);
log('Pin0=',$p0,'Pin1=',$p1);
log($v0,$v1,$v2);
log('Temp:',$temp,'Hum:',$hum);
```

Особенности:
- Поддерживает несколько параметров через запятую
- Автоматически добавляет пробел между параметрами
- Строки только в одинарных кавычках


## Математические операции

```scriptrunner
$v0=10+5;
$v1=10-3;
$v2=10*3;
$v3=10/3;

$v4=10&3;     // AND
$v5=10|3;     // OR
$v6=10^3;     // XOR
$v7=10<<2;    // Сдвиг влево
$v8=10>>1;    // Сдвиг вправо
$v9=10%3;     // Остаток от деления
```

## Работа с массивами

```scriptrunner
// Инициализация
$a0={1,2,3,4,5};

// Длина массива
$v0=len($a0);

// Чтение элемента
$v1=get($a0,0);

// Запись элемента
set($a0,2,10);

// Заполнение
$v0=0;
while:$v0<5;
set($a0,$v0,$v0*10);
$v0=$v0+1;
end;
```

## Работа со строками

```scriptrunner
// Конкатенация
$s0='Hello ';
$s1='World';
$s2=$s0+$s1;

// Длина строки
$v0=len($s0);

// Код первого символа
$v1=ord($s0);    // 'H' -> 72

// Символ по коду
$s3=chr(65);     // 65 -> 'A'
```

## Внешние функции и переменные

```scriptrunner
$temp=udp(2);
$hum=fade(2,255,1000);

log('Temp:',$temp);
if:$temp>30;
 log('Too hot!');
end;
```

## Примеры скриптов

### Мигание светодиодом

```scriptrunner
$p2=255;wait(500ms);$p2=0;wait(500ms);
```

### Счетчик

```scriptrunner
$v0=0;while:$v0<10;log('Count:',$v0);$v0=$v0+1;wait(1s);end;log('Done!');
```

### Плавное зажигание

```scriptrunner
$v0=0;
while:$v0<5;
  fade(14,255,1000);
  wait(1s);
  fade(14,0,1000);
  wait(1s);
  $v0=$v0+1;
end;
```

### Кнопка управляет светодиодом

```scriptrunner
$state=0;
on('btn_click');
 if:$state==0;
  $state=1;
  $p2=255;
  log('ON');
 else;
  $state=0;
  $p2=0;
  log('OFF');
 end;
end;
```

## Ограничения

- Максимальная длина скрипта: 256 символов
- Максимум скриптов одновременно: 15 
- Минимальная задержка: ~10ms
- Нет пробелов вне строк
- Только одинарные кавычки '
- Нет дробных чисел в wait()
- Нет комментариев


## Краткая шпаргалка

Разделитель                 ;
Строки                      'текст'
Пробелы                     только внутри строк
Переменные                  $v0, $i0, $f0, $s0, $a0
Задержка                    wait(100ms), wait(1s), wait(1m), wait(1h)
Цикл                        while:условие; ... end;
Условие                     if:условие; ... else; ... end;
Событие                     on('имя'); ... end;
Лог                         log(параметр1,параметр2,...);
Порты                       $p13
Плавное изменение (ШИМ)     $p14=255/20;
