# Project images

- `screen/` — project screenshots. The catalog on [vuesp.ru](https://vuesp.ru)
  builds the screenshot gallery from every image in this directory.
- `cover.png` — optional cover image. If present, it is used as the project
  preview; otherwise the catalog renders the default Vuesp cover template.

Recommended screenshot size: 1440×900 or 1600×1000, PNG or WebP.
